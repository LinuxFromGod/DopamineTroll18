# FakeDopamine

**LARPMINE** — «Dopamine LARP»: приложение для ларпа и статуса, как LARP-приложения
в TrollStore (фейковые деньги и т.п.), только здесь ларп — фейковый джейлбрейк.
Автор — [LinuxFromGod](https://github.com/LinuxFromGod), Telegram:
[@holygentoo](https://t.me/holygentoo)) — автономное iOS-приложение, которое
полностью **имитирует** Dopamine 3.0.13:
реальный интерфейс, реальная последовательность логов, boot-экран, паника ядра,
выбор менеджера пакетов и смена темы. При этом оно **ничего не делает с системой**:
нет `libjailbreak`, нет эксплойтов, нет записи в системные разделы и нет самого
джейлбрейка.

Приложение можно собрать и запустить в симуляторе iPhone без подписи. Для сборки
требуются macOS и Xcode; GitHub Actions выполняет сборку на macOS runner и
публикует `.app` симулятора как workflow artifact.

## Что умеет

- Полный сценарий «джейлбрейка»: patchfinding → kernel exploit → PAC/PPL/SPTM bypass →
  phys R/W → bootstrap → trust cache → environment → protection → bind mount.
- Живой лог в стиле Dopamine (анимированные строки) и подробный debug-лог.
- Экран выбора Sileo/Zebra при первом запуске.
- Настройки: эксплойты, tweak injection, verbose logs, App JIT, jetsam multiplier,
  удаление джейлбрейка, тема, boot-логотип, сброс настроек.
- Respring: настоящий сигнал SpringBoard там, где окружение позволяет
  (TrollStore или реальный джейлбрейк), иначе имитация. Userspace reboot
  с boot-экраном, чей прогресс идёт неровными «загрузочными» кусками.
- Режим `Kernel Panic`: реалистичный panic dump, после которого «устройство
  перезагружается» и состояние джейлбрейка сбрасывается. Паника также случайно
  случается в ~7% обычных запусков.
- Смена иконки приложения вместе с темой (AppIcon_ElleKit / Red / Purple / Blue).
- Русская, английская, немецкая, испанская и французская локализации.

## Требования

- macOS с Xcode 15 или новее (подойдёт и Xcode 16).
- iOS Simulator с iOS 15.0+.
- Для запуска на реальном устройстве — Apple ID / development team в Xcode,
  либо установка подписанного/беззнакового IPA через TrollStore.

## Поддержка устройств и версий

Deployment target — iOS 15.0. Приложение рассчитано на весь спектр устройств
от A9 до A20:

| Чип | Устройства (примеры) | iOS |
| --- | --- | --- |
| A9–A10 | iPhone 6s/7/SE 2016, iPad 5–7, iPod touch 7 | 15.0 – 16.6.1 |
| A12–A13 | iPhone XS/XR/11 | 15.0 – 27.3 |
| A14–A20 | iPhone 12 и новее, включая актуальные модели | 15.0 – 27.3 |

Заголовок приложения показывает диапазон поддержки для текущего устройства:
на arm64e-чипах (A12+) — «iOS 15.0 - 27.3 (SPTM/PPL)», на A9/A10 —
«iOS 15.0 - 16.6.1 (bypasses)». Определение arm64e идёт через
`hw.optional.arm64e` с откатом к списку cpu family, поэтому свежие чипы
(A19/A20) тоже распознаются корректно.

## Сборка и запуск

1. Откройте `FakeDopamine.xcodeproj` в Xcode.
2. Выберите схему `FakeDopamine` и любой iPhone-симулятор.
3. Нажмите **Run** (⌘R).

### GitHub Actions

Workflow `.github/workflows/ios-build.yml` («iOS Build (IPA)») собирает
беззнаковый архив под устройство (iphoneos) и упаковывает его в IPA при push
в `main`, pull request и вручную через **Actions → iOS Build (IPA) → Run
workflow**. Готовый файл доступен в артефакте `unsigned-ipa` в течение 14 дней.

Беззнаковый IPA предназначен для установки через TrollStore. Для обычной
сборки под себя в Xcode выберите таргет `FakeDopamine` → **Signing &
Capabilities**, укажите **Team** и запустите на подключённом iPhone.

Дисплейное имя приложения — **LARPMINE**, имя проекта и таргета — `FakeDopamine`.
На главном экране и в кредитах указан автор; в кредитах есть ссылки на GitHub
и Telegram.

## Как пользоваться

1. Запустите приложение.
2. Нажмите большую кнопку **Jailbreak**.
3. Если менеджеры пакетов ещё не выбраны, выберите Sileo и/или Zebra и нажмите
   **Continue**.
4. Дождитесь окончания лога: приложение покажет boot-экран (или панику) и
   «перезапустится» уже в состоянии «Jailbroken».
5. После этого доступны настройки, respring и userspace reboot.

Сбросить всё состояние можно через **Settings → Reset Settings** или удалив
приложение (настройки хранятся в `NSUserDefaults` под ключом `DOPreferences`).

## Важно

- Это **симулятор**, а не джейлбрейк. Он не устанавливает пакеты, не меняет
  систему и не требует эксплойтов.
- Все «системные» действия — визуальная имитация, кроме одного: **respring**.
  «Restart SpringBoard» и финал джейлбрейка пытаются выполнить настоящий
  респринг (сигнал SpringBoard через `proc_listallpids` + `kill`). Это
  срабатывает только там, где окружение разрешает сигналы чужим процессам —
  установка через TrollStore или настоящий джейлбрейк. В обычной (sandboxed)
  установке и в симуляторе сигнал не проходит, и приложение откатывается к
  внутриигровой имитации: экран гаснет, UI перезапускается.
- Удаление «джейлбрейка» сбрасывает всё симулированное состояние: менеджеры
  пакетов, состояние bootstrap и версию, после чего показывает boot-экран и
  перезапускает UI (с попыткой реального респринга там, где он возможен).
- Исходники интерфейса основаны на Dopamine 3.0.13 (MIT, © Lars Fröder / opa334).
